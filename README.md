# 아베라 웹 체험

제품 없이 위치 선택, 가상 도포, 예시 기록 조회를 해볼 수 있는 한국어 정적 웹사이트입니다. `index.html`을 열거나 이 폴더에서 `python -m http.server 8000`을 실행해 확인할 수 있습니다.

HTML·CSS·JavaScript만 사용합니다. 예시 기록은 현재 브라우저 탭의 세션 저장소에 남으며 다시 체험하면 지워집니다. 서버로 전송하는 폼이나 외부 분석 스크립트는 없습니다.

## 시각 자료

- 기기 이미지 세 장은 프로젝트에서 제공한 2026년 10월 15일자 AVERA 6방향 외관 콘셉트 시안의 사선·정면·측면입니다.
- 정수리 사진은 웹 시뮬레이션을 위해 이미지 생성 도구로 제작한 합성 예시입니다. 생성 지시는 익명의 성인 정수리를 수직으로 내려다본 구도, 중앙의 가마, 짙은 갈색 머리와 중립 조명, 문자·기기·UI 제외입니다. 한 이미지에서 선택한 두 지점을 각각 확대합니다.
