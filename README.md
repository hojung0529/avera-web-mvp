# 아베라 웹 체험

왼쪽 두피 뷰에서 A 또는 B를 고른 뒤 오른쪽 ESP32 모의 화면에서 위치별 도포를 체험합니다. [GitHub Pages에서 열기](https://hojung0529.github.io/avera-web-mvp/#experience)

- 포인트 모드에서는 도포 키를 한 번 누를 때 한 번 작동합니다. 연속 모드는 누르는 동안 설정 간격으로 반복합니다.
- 총 도포량, 1포인트량, 도포 간격, 누적 게이지, 카트리지 교체를 조작할 수 있습니다. 수치는 컨트롤러의 가상 작동을 보여주는 예시입니다.
- 키보드에서는 Tab으로 이동하고 Space 또는 Enter로 조작합니다. 기록에는 선택 위치, 예시 이미지, 시작 시각, 모드, 횟수와 가상 작동량이 남습니다. 한 번 길게 누른 작동은 한 묶음으로 표시합니다.
- HTML·CSS·JavaScript로 동작하고 외부 의존성이 없습니다. 이 폴더에서 `python -m http.server 8000`을 실행해 미리 볼 수 있습니다. 기록은 현재 탭의 세션 저장소를 사용합니다.

## 시각 자료와 동작 근거

프로젝트에서 제공한 AVERA 6방향 외관 콘셉트의 정면·측면을 갤러리에 사용했습니다. 첫 화면의 기기 이미지는 사선 시안을 참조해 청색 조명으로 새로 생성한 콘셉트입니다. 정수리와 스포이드 사진 역시 웹 체험에 사용하기 위한 생성 이미지입니다.

개발 계획 섹션의 무음 영상은 강원청년창업경진대회 최종결선 발표자료 S6b의 약 6.05~8.68초, 12.65~15.28초를 발췌해 스포이드와 가르마를 중심으로 재편집했습니다. 뷰포트에 들어오면 재생하며, 동작 줄이기를 사용하면 재생 버튼을 눌러 볼 수 있습니다.

320×170 AVERA 컨트롤러의 화면 배치와 펌웨어의 두 모드, 설정 범위, 누적·잔량 동작을 웹에서 재현했습니다. 두피 위치 선택과 탭 기록은 이 웹 체험의 기능입니다. 실제 기기와의 통신 및 카메라 입력은 사용하지 않습니다.
